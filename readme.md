# CCTweaked scripts
This is just a repository where I will be storing some scripts I use in my minecraft worlds. I live in a 
country where pastebin is blocked, however github is not. Hence, I will use github raw file links to import 
scripts into my turtles.

## Why?
I originally wanted to make a minecraft modpack to imitate Autonauts because I could not play the actual game. 
I decided upon using an actual scripting language since that was the closest thing I have at the moment anyways. 
It just so happened to result in this repository where you can all publicly see what I am working on when I am 
not working on one of my main projects.
